# ReactPHP Child Process Messenger Child Interface Example

A simple example demonstrating the use of ReactPHP's Child Process Messenger with a child interface.

## Table of Contents

## Overview

This repository provides a basic example of how to use ReactPHP's Child Process Messenger with a child interface. It's designed to help developers understand the integration and usage of child processes in a ReactPHP environment.

## Requirements

- PHP 7.4 or higher
- Composer

## Installation

1. Clone the repository:

```bash
git clone https://github.com/WyriHaximus/reactphp-child-process-messenger-child-interface-example.git
cd reactphp-child-process-messenger-child-interface-example
```
2. Install dependencies using Composer:

```bash
composer install
```
   
## Usage

To run the example:

```bash
php example.php
```

This will execute the `example.php` script, demonstrating the functionality of the child process messenger with a child interface.
